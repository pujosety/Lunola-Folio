Lunola Folio portable mode

While this file sits next to lunola-folio.exe, Lunola Folio keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the Lunola FolioData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Lunola Folio with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\Lunola Folio and
%LOCALAPPDATA%\Lunola Folio) instead. If Lunola FolioData can't be written (for example on a read-only
drive), Lunola Folio says so and uses the per-user folders instead.
